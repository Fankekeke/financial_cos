# 基于 SpringBoot + Vue 的家庭理财系统 (Family Financial Management System)

资产总览 · 收支记录 · 固定资产 · 债务债券 · 基金股票 · 保险管理 · 报表统计 · 数据可视化

本项目是一套面向家庭用户的个人与家庭财务管理工具，采用前后端分离架构，覆盖管理员与用户两类角色。系统围绕"资产管理、收支记录、固定资产、债务债券、基金股票、保险管理、报表统计"等核心业务设计，支持用户记录家庭收入与支出、管理固定资产与债务、跟踪基金与股票持仓、管理保险保单，并通过可视化报表直观展示家庭财务状况，帮助用户建立清晰的财务认知，适用于家庭日常记账、个人资产管理、投资组合跟踪及保险保单管理。

## 核心特性

- **资产总览**：汇总家庭全部资产（现金、存款、基金、股票、固定资产等）与负债（贷款、信用卡、债券等），实时计算净资产，一目了然掌握家庭财务全貌。
- **收支记录管理**：记录家庭日常收入（工资、奖金、投资收益、兼职收入等）与支出（餐饮、交通、教育、医疗、娱乐等），支持分类管理与月度对比。
- **固定资产管理**：登记家庭固定资产（房产、车辆、贵重物品等），记录购入时间、购入价格、当前估值、折旧情况。
- **债务债券管理**：记录家庭负债（房贷、车贷、信用卡欠款、私人借款等）与持有的债券（国债、企业债等），跟踪还款进度与利息支出。
- **基金与股票跟踪**：记录基金与股票的持仓信息（买入价格、持有份额、当前市值），系统自动计算盈亏，展示投资收益走势。
- **保险管理**：管理家庭保险保单（寿险、医疗险、重疾险、意外险、车险等），记录保单信息、缴费周期、到期提醒、理赔记录。
- **保险推荐**：根据家庭结构与财务状况，展示适合的保险产品类型参考信息，帮助用户了解保障缺口（仅供参考，不构成投保建议）。
- **报表统计**：以图表形式展示收支趋势、资产分布、负债结构、投资收益、保险覆盖率等数据，辅助家庭财务决策。

## 功能模块概览

## 管理员端

管理员负责平台整体运营、基础数据配置、内容管理与系统维护：

### 基础数据管理

- **收支分类管理**：配置收入与支出的分类体系，如工资、奖金、投资收益、餐饮、交通、教育、医疗、娱乐等，支持分类增删改查。
- **资产分类管理**：配置资产分类，如现金、银行存款、基金、股票、房产、车辆、其他固定资产等。
- **保险类型管理**：配置保险产品类型，如寿险、医疗险、重疾险、意外险、车险、财产险等，维护保险知识科普内容。

### 内容与推荐管理

- **保险推荐管理**：维护保险推荐信息，包括保险产品名称、保险公司、保障类型、适用人群、保障范围、参考保费区间等，供用户参考（仅为信息展示，不构成投保建议）。
- **理财知识管理**：发布理财知识文章与科普内容，帮助用户学习基础理财知识。

### 用户与系统管理

- **用户管理**：管理注册用户信息，包括姓名、手机号、注册时间、账户状态，支持账号启用/禁用。
- **公告管理**：发布平台公告，包括系统维护通知、理财知识推送、功能更新说明等。
- **数据统计**：查看平台整体运营数据，包括注册用户数、活跃用户数、资产总额分布、收支趋势等。

## 用户端

用户面向家庭用户，提供资产管理、收支记录、投资跟踪、保险管理与报表统计功能：

### 资产总览

- **资产总览**：首页展示家庭财务全景，包括总资产、总负债、净资产、本月收入、本月支出、本月结余，以卡片与图表形式直观呈现。

### 收支管理

- **收入记录**：记录家庭各项收入，包括收入金额、收入分类、收入来源、备注说明、收入日期，支持按月/年汇总统计。
- **支出记录**：记录家庭各项支出，包括支出金额、支出分类、支付方式（现金/微信/支付宝/银行卡）、备注说明、支出日期，支持按月/年汇总统计。

### 资产与负债管理

- **资产管理**：登记与管理家庭资产，包括现金、银行存款、基金持仓、股票持仓、固定资产等，实时更新资产总值。
- **固定资产**：管理家庭固定资产信息，包括资产名称、资产类型、购入时间、购入价格、当前估值、存放位置、资产图片，支持折旧计算。
- **债务债券**：管理家庭负债与债券信息，包括负债名称（房贷/车贷/信用卡等）、负债总额、剩余未还、月还款额、利率、到期日期；债券包括债券名称、面值、持有数量、票面利率、到期日期、当前市值。

### 投资管理

- **我的基金**：记录基金持仓信息，包括基金名称、基金代码、买入价格、持有份额、当前净值、当前市值、累计收益、收益率，支持手动更新净值或对接行情数据。
- **我的股票**：记录股票持仓信息，包括股票名称、股票代码、买入价格、持有数量、当前股价、当前市值、累计盈亏、盈亏比例，支持手动更新股价或对接行情数据。

### 保险管理

- **保险管理**：管理家庭保险保单，包括保险名称、保险公司、保险类型、被保险人、保额、年缴保费、缴费期限、保单生效日期、保单到期日期、缴费提醒设置，支持保单到期提醒与理赔记录。
- **保险推荐**：浏览平台推荐的保险产品信息，了解不同保险类型的保障范围与适用人群，辅助家庭保障规划（仅供参考，具体投保请咨询正规持牌保险机构）。

### 报表与统计

- **报表统计**：以图表形式展示家庭财务数据，包括：
  - 收支趋势图（月度/年度收入与支出对比）
  - 支出分类占比图（各类支出占比）
  - 资产分布图（各类资产占比）
  - 负债结构图（各类负债占比）
  - 投资收益走势图（基金/股票收益变化）
  - 净资产变化趋势图
